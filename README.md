# InfoJobs - Busca de Empregos

Projeto desenvolvido durante as disciplinas de Backend e Frontend do curso de Tecnologia em Análise e Desenvolvimento de Sistemas.

## Como executar o Backend

1 - Clone o repositório do projeto com:

```bash
git clone https://github.com/Mariana-Salmaza/Busca-Empregos-app.git
```

2 - Configure um arquivo `.env` no diretório `Back/` com as credenciais necessárias.

3 - Acesse o diretório do projeto (`Back/`) com:

```
cd Back/
```

4 - Instale as dependências com:

```bash
npm i
```

5 - Execute a aplicação com:

```
npm run dev
```

6 - Execute os casos de teste com:

```
npm run test
```

## Como executar o Frontend

1 - Clone o repositório do projeto, caso ainda não tenha sido.

2 - Acesse o diretório do projeto (`Front/`) com:

```
cd Front/
```

3 - Instale as dependências com:

```bash
npm i
```

4 - Execute a aplicação com:

```
npm run dev
```

5 - Assim, o aplicativo deve estar acessível em http://localhost:5173.
